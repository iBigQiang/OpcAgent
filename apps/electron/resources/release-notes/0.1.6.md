# OPC Agent 0.1.6

这是 0.1.4 之后的首个公开版本，同时包含已在本机验证的 0.1.5 测试版改动。

### 新增

- 为 AnyRouter-Pi 增加默认关闭的安全诊断日志，可记录 HTTP 状态、耗时、请求次数、Retry-After、模型别名、请求路径、实验变量、Token 上限和重试头；不会记录密钥、提示词、完整 URL 或响应正文。
- 为 AnyRouter-Pi 增加相互隔离的请求实验，可单独保留模型别名、SDK Token 上限或真实重试次数，便于定位上游限流差异。
- 增加保留完整自定义 Base URL 的模式，支持不按内置协议规则补全请求路径。
- 为内置 Google AI Studio 补充 Gemini 3.5 Flash-Lite、Gemini 3.6 Flash 和 Gemini 3.7 Flash，并在 Pi 运行时完整注册这些模型。

### 修复

- 修复自定义 Google Gemini 协议把 SDK Base URL 保存为 `/v1beta/models` 后，运行时再次拼接 `models/`，最终形成 `/v1beta/models/models/...` 的问题。
- 自定义 Gemini 现在保存 `/v1beta` 版本 Base URL，并由 Google SDK 生成 `/v1beta/models/{model}:streamGenerateContent?alt=sse`。
- 阻止 AnyRouter-Pi 请求发生网络异常后再次发送一条未经改写的原始请求。
- 保留并传递自定义完整请求 URL，使非标准路径的服务商能够收到用户配置的地址。
- 修复 Windows 安装包缺少 Telegram SDK 导致连接不可用的问题。
- 统一 Telegram Token 测试和机器人轮询的网络客户端，展示安全的连接阶段错误，并将轮询失败同步到桌面状态。
- 机器人离线时仍保留已保存的 Telegram 配置，并修正会话绑定读取的实际消息运行时。
- 为尚未绑定私聊的已授权 Telegram 用户增加引导流程：新建默认模型会话或选择现有会话后，自动投递原始消息。
- 在 Telegram 私聊绑定列表中显示对应的 OPC Agent 会话、实际渠道和模型。
- 修复 Windows 安装器完成步骤在开始菜单快捷方式尚未就绪时尝试启动应用的问题。
